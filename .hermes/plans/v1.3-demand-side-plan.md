# bubble-watch — v1.3 implementation plan: close the demand gap

> **For Hermes:** use the `subagent-driven-development` skill to execute this task-by-task.
> One fresh subagent per task, spec-compliance review then code-quality review before proceeding.

**Goal:** Add the model's missing demand side — measure whether AI compute is actually being *used*
and where the revenue is going — from free, keyless, live sources.

**Architecture:** Three new scored indicators (`inference_demand`, `international_demand`,
`energisation_delay`), one correctness fix (make `frontier_premium` live), and one new falsifier
(`export_controls`). Each is a normal `Indicator` impl registered in `indicators::find()`, fetching
through the existing `Fetcher`, scored via `score::interpolate` against config anchors, and
degrading to a reported gap on any failure. Methodology bumps 2.2 → 2.3, and the archive refuses
cross-version baselines automatically.

**Tech stack:** Rust (existing), `ureq` via `Fetcher`, TOML config, stdlib JSON (`serde_json` is
already a dependency — verify before relying on it).

**Evidence base:** `.hermes/analysis/2026-09-20-next-signals-plan.md` and the `L1/L1b/L2/L4/L5`
lens reports in `.hermes/recon/2026-09-20/`. Every endpoint below was probed live on 2026-09-20;
the two headline claims (OpenRouter token volume, Federal Register count) were re-verified by the
orchestrator independently. **Do not re-probe what is listed as verified; do not trust anything
listed as a dead end.**

---

## Standing rules (non-negotiable, from the existing project contract)

1. **Never print a number the source did not supply.** Absent → `Reading::Unavailable` with a reason.
   Never 0.0, never imputed, never stale-carried.
2. **Every `Reading::Scored` carries a `Provenance`** with real `source`, `endpoint`, `as_of`,
   `retrieved_at`.
3. **A failed fetch is a gap that contributes nothing**, and coverage shrinks visibly.
4. **State the direction of the bias** when a gap makes the score look calmer than reality.
5. **Methodology version bumps on any redefinition**; the archive refuses cross-version baselines.
6. **A large number is not automatically bearish.** Backlog, demand and adoption cut both ways and
   the report must say so.

**Step 3: Implement minimally**

```rust
//! OpenRouter public token-volume endpoints.
//!
//! Verified 2026-09-20: keyless, no auth header, 200. See
//! `.hermes/recon/2026-09-20/L2-utilization.md`.
//!
//! This is the only free public measurement of AI *usage* the project has found:
//! it answers "is the compute being used", which the model previously could not.

use crate::http::Fetcher;

pub const RANKINGS_MODELS: &str =
    "https://openrouter.ai/api/frontend/v1/rankings/models";
pub const RANKINGS_CHART: &str =
    "https://openrouter.ai/api/frontend/v1/rankings/model-rankings-chart";

#[derive(Debug, Clone, PartialEq)]
pub struct DailyTokens {
    pub date: String,
    pub total_tokens: u64,
}

pub fn parse_token_volume(body: &str) -> Result<Vec<DailyTokens>, String> {
    let v: serde_json::Value =
        serde_json::from_str(body).map_err(|e| format!("ranks payload unparseable: {e}"))?;
    let rows = v
        .get("data")
        .and_then(|d| d.as_array())
        .ok_or_else(|| "no `data` array in the rankings payload".to_string())?;
    let mut by: std::collections::BTreeMap<String, u64> = Default::default();
    for r in rows {
        let date = r.get("date").and_then(|d| d.as_str()).unwrap_or("");
        if date.is_empty() {
            continue;
        }
        let day = date.split(' ').next().unwrap_or(date).to_string();
        let p = r.get("total_prompt_tokens").and_then(|x| x.as_u64()).unwrap_or(0);
        let c = r.get("total_completion_tokens").and_then(|x| x.as_u64()).unwrap_or(0);
        *by.entry(day).or_insert(0) += p + c;
    }
    if by.is_empty() {
        return Err("rankings payload contained no dated rows".into());
    }
    Ok(by
        .into_iter()
        .map(|(date, total_tokens)| DailyTokens { date, total_tokens })
        .collect())
}

/// Share of tokens going to open-weight models, given the set of model slugs
/// that publish weights (from the models catalogue's `hugging_face_id`).
pub fn open_weight_share(body: &str, open_slugs: &[&str]) -> Result<f64, String> {
    let v: serde_json::Value =
        serde_json::from_str(body).map_err(|e| format!("unparseable: {e}"))?;
    let rows = v.get("data").and_then(|d| d.as_array()).ok_or("no data array")?;
    let mut open = 0u64;
    let mut all = 0u64;
    for r in rows {
        let t = r.get("total_prompt_tokens").and_then(|x| x.as_u64()).unwrap_or(0)
            + r.get("total_completion_tokens").and_then(|x| x.as_u64()).unwrap_or(0);
        all += t;
        let slug = r.get("model_permaslug").and_then(|x| x.as_str()).unwrap_or("");
        if open_slugs.contains(&slug) {
            open += t;
        }
    }
    if all == 0 {
        return Err("no tokens in window".into());
    }
    Ok(open as f64 / all as f64)
}
```

#[test]
fn demand_stress_rises_when_the_growth_rate_decelerates() {
    // The signal is the RATE OF CHANGE, not the level. Falling growth while the
    // level is still high is the early warning the model currently cannot see.
    let fast = [1.0e13, 2.0e13, 3.0e13]; // ~100% growth per period
    let slow = [3.0e13, 3.1e13, 3.2e13]; // ~3% growth, high level
    assert!(
        growth_stress(&slow) > growth_stress(&fast),
        "deceleration must read as HIGHER stress even at a higher level"
    );
}

#[test]
fn a_short_series_is_unavailable_not_extrapolated() {
    // Two points cannot establish a rate of change honestly.
    let r = demand_reading(&[1.0e13]);
    assert!(matches!(r, Reading::Unavailable { .. }), "must refuse, not guess");
}

## Risk register

|---|---|---|
| OpenRouter endpoints are **undocumented frontend routes** | they may change without notice; the whole demand indicator rests on one | the gap contract handles breakage gracefully, but add a test asserting the parse shape, and record the date verified |
